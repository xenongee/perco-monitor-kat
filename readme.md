# perco-monitor

Веб-приложение для мониторинга присутствия студентов в общежитиях на основе данных системы контроля доступа PERCo-Web.

## Требования

- Node.js >= 20.6 (используются нативные `fetch` и флаг `--env-file`)

## Установка и запуск

1. Установите зависимости:
   ```bash
   npm install
   ```
2. Создайте файл конфигурации `.env` в корне проекта и укажите параметры подключения:
   - `PERCO_URL` — базовый адрес PERCo-Web API
   - `PERCO_LOGIN` — имя пользователя для авторизации в API
   - `PERCO_PASSWORD` — пароль пользователя API
   - `PORT` *(опционально)* — порт HTTP-сервера (по умолчанию 3000)
   - `PERCO_TOKEN` *(опционально)* — кэшированный токен авторизации
3. Запустите приложение:
   ```bash
   npm start
   ```
   Для разработки с автоматическим перезапуском при изменениях:
   ```bash
   npm run dev
   ```

Интерфейс доступен по адресам общежитий `/obch1` и `/obch2`, а также на главной странице выбора `/`.
